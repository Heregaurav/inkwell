# Inkwell Interview Preparation

This folder contains a repository-grounded interview guide. Start at the [root guide](../PROJECT_INTERVIEW_PREPARATION.md), then use these modules:

1. [Overview and architecture](01-overview-architecture.md): project pitch, stack, six Mermaid diagrams, workflows, architecture trade-offs.
2. [Technology deep dive](02-technology-deep-dive.md): seven stack-layer deep dives with ten interview drills per layer.
3. [Codebase, backend, and database](03-code-backend-database.md): file/module walkthrough, end-to-end flows, API engineering, schema/index analysis.
4. [Scalability, security, and performance](04-scale-security-performance.md): user-growth stages, proposed architecture, security findings and fixes, bottleneck/benchmark plan.
5. [Failures and decisions](05-failures-and-decisions.md): twenty debugging scenarios and fifteen evidence-backed design decisions.
6. [100-question bank](06-question-bank-100.md): exactly 100 project-specific questions with ideal answer, concept, follow-up, follow-up answer, code reference, and common mistake.
7. [Mock interviews and revision](07-mock-and-revision.md): three simulated rounds, resume-claim caveats, revision sheets, demo, and readiness checklist.
8. [Technology crosswalk](08-technology-crosswalk.md): internal roles, replacement impact, high-traffic pressure, and technology boundaries for each major dependency.

**Evidence policy:** Code/config is treated as the source of truth. Recommendations are labeled as proposed. No resume, benchmark, automated test results, production deployment status, or performance metrics were supplied or verified.
